# 세상에서 가장 귀찮은 계산기

「훈민정음으로 하루 한 번 코딩」의 첫 번째 앱입니다.

영상에 가장 먼저 달린 요청 댓글을 고치지 않고 그대로 AI에게 넘기면, AI가 훈민정음으로 이 계산기의 코드를 고칩니다. 사람은 코드를 고치지 않습니다. 바뀐 화면은 다음 영상에서 보여 드립니다.

훈민정음은 셈틀이 만든 한국어 프로그래밍 언어입니다. → https://hmje.semtle.net

## 날마다 바뀐 것

| 날 | 요청 댓글 | AI가 바꾼 것 |
|---|---|---|
| 0일차 | (시작) 아주 평범한 계산기 | 숫자 0~9, 사칙연산, 지우기 키가 있는 계산기 |

하루에 커밋 하나씩 남깁니다. 커밋끼리 비교하면 그날 AI가 바꾼 줄을 그대로 볼 수 있습니다. 날짜별 태그: `day-0`.

## 직접 빌드하기

훈민정음 도구(`hmjec`)가 필요합니다. 설치 방법은 https://hmje.semtle.net 에 있습니다.

```
hmjec --project . --artifact 계산기 --target windows-exe -o build/계산기.exe
```

이 프로젝트는 Windows 10 이상을 대상으로 합니다(`Project.hmjep`).
